Non-Blocking UART Parser (DMA, CRC16) for Hardware PWM Power Control
Pet Project (Firmware) · STM32F3DISCOVERY · Rust (no_std) · 2026 · GitHub

Implemented non-blocking variable-length command reception via a circular DMA buffer and USART IDLE interrupt, calculating received byte counts using the hardware DMA counter. Secured the command protocol with hardware CRC-16 validation. Controlled the power load via hardware PWM on TIM3. PID Temperature Control System
Coursework Project · STM32F3DISCOVERY · Rust · 2026 · GitHub

Developed a closed-loop liquid temperature control system based on an STM32 microcontroller. Implemented a bit-banged 1-Wire interface to poll a DS18B20 sensor with CRC-8 packet validation. Combined a mathematical PID controller with a bang-bang mode for rapid heating during large temperature errors. Regulated heater power (12V, 50W) using time-proportional control via an electromechanical relay. Enabled live tuning of PID gains and setpoints via UART commands without halting system operation. Implemented telemetry output to an OLED display (I2C) and serial terminal. Designed the circuit schematic in KiCad.
