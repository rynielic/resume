Проекты и опыт

Асинхронный парсер бинарного протокола по UART с использованием DMA
Пет-проект (Firmware) · STM32F303 · Rust (no_std) · 2026 · GitHub

Неблокирующий UART-интерфейс управления нагревателем (RTIC, STM32F303) с приёмом команд переменной длины: кольцевой DMA + прерывание USART IDLE, число принятых байт считается по счётчику DMA. Аппаратный ШИМ на TIM3, CRC-16 команд через периферию CRC, аварийный останов по EXTI0 и по команде STOP с явным RESUME. В idle ядро засыпает (WFI) и просыпается по прерыванию; приём данных по DMA и ШИМ на TIM3 продолжают работать, пока ядро спит. Регистры (PAC) использованы там, где HAL не покрывает задачу. Unit-тесты разбора команд; силовой каскад на MOSFET IRLB8721 спроектирован и спаян.

Отказоустойчивая многопоточная CLI-утилита телеметрии Serial/UART
Инструментарий (Host) · Linux / PC · Rust (std) · 2026 · GitHub

Консольная утилита (Rust, std) для работы с МК по UART: выбор порта, два потока (чтение и запись), флаг отмены на AtomicBool, CRC-16/CCITT-FALSE, совпадающий с аппаратным CRC STM32, повторный выбор порта после ошибки записи.

Система контроля температуры с ПИД-регулятором
Курсовой проект · STM32F3DISCOVERY · Rust · 2026 · GitHub

Замкнутая система термостабилизации (200 мл воды, цель ±1 °C): 1-Wire реализован программно (bit-banging) с проверкой CRC-8, ПИД-регулятор с полной мощностью при большой ошибке, пропорциональное по времени управление реле нагревателя 12 В / 50 Вт, телеметрия на OLED (I2C) и по UART, настройка коэффициентов командами. Схема в KiCad.

Дополнительно

Архитектура прошивок: разработка событийно-ориентированного неблокирующего кода на базе аппаратных прерываний (NVIC), таймеров и DMA. Снижение энергопотребления и разгрузка ядра через перевод МК в режим ожидания прерываний (WFI / Sleep mode). Строгий контроль памяти без использования кучи (static allocation) и безопасная синхронизация в реальном времени (RTIC).

Аппаратная и программная отладка: пошаговая отладка на железе через интерфейс SWD (ST-LINK, OpenOCD + GDB, probe-rs, логирование по RTT). Написание сопутствующих скриптов на Python для сбора и анализа телеметрии с ПК (PySerial). Поиск аппаратных неисправностей, прозвонка цепей и проверка уровней сигналов мультиметром, ручной монтаж макетных плат.

Документация и стандарты: свободное чтение технической документации на английском языке (Datasheets, Reference Manuals, Errata, уровень B2). Опыт разработки и оформления конструкторской и программной документации по ГОСТ (ЕСКД / ЕСПД): схемы электрические принципиальные, перечни элементов, пояснительные записки и ТЗ.
