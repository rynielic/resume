Проекты и опыт

Асинхронный парсер бинарного протокола по UART с использованием DMA
Пет-проект (Firmware) · STM32F303 · Rust (no_std) · 2026 · GitHub

Реализовал неблокирующий прием пакетов переменной длины на уровне регистров (PAC) без оверхеда HAL. Настроил кольцевой буфер DMA (Circular mode) в связке с прерываниями по простою линии (USART IDLE). Внедрил аппаратную проверку целостности пакетов через встроенный периферийный модуль CRC и перевел ядро в режим сна (инструкция WFI) на время фоновой пересылки данных.

Отказоустойчивая многопоточная CLI-утилита телеметрии Serial/UART
Инструментарий (Host) · Linux / PC · Rust (std) · 2026 · GitHub

Разработал десктопную утилиту для обмена данными с МК. Реализовал двухпоточную архитектуру (разделение I/O и обработки) с синхронизацией через атомарные примитивы (Atomics). Внедрил интерактивный выбор порта, программный побитовый расчет CRC (синхронизированный с аппаратным блоком STM32) и автоматическое переподключение (auto-reconnect) при обрыве связи без падения программы.

Система контроля температуры с ПИД-регулятором
Курсовой проект · STM32F3DISCOVERY · Rust · 2026 · GitHub

Разработал замкнутую систему терморегуляции на базе микроконтроллера STM32F303. Реализовал опрос датчика DS18B20 по протоколу 1-Wire, вывод телеметрии в реальном времени на OLED-дисплей SSD1306 (I2C) и логирование данных на ПК по UART. Написал алгоритм ПИД-регулятора для управления нагревательным элементом. Спроектировал электрическую принципиальную схему в KiCad.
