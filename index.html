Проекты и опыт

Асинхронный UART-парсер (DMA, CRC16) для аппаратного PWM-управления силовой нагрузкой
Пет-проект (Firmware) · STM32F3DISCOVERY · Rust (no_std) · 2026 · GitHub

Реализован неблокирующий прием команд переменной длины через кольцевой буфер DMA и прерывание USART IDLE. число принятых байт вычисляется через аппаратный счетчик DMA. Протокол команд защищен вычислением CRC-16 аппаратным модулем. Нагрузка управляется через аппаратный ШИМ на TIM3. Настроена система аварийной остановки по аппаратному прерыванию EXTI0 и команде STOP с явным RESUME. В цикле простоя ядро переводится в режим ожидания (WFI) для экономии энергии и просыпается по прерыванию, при этом прием данных и генерация ШИМ функционируют аппаратно. Управление периферией реализовано через прямой доступ к регистрам (PAC) из-за архитектурных ограничений HAL. Разработаны unit-тесты логики парсера. Спроектирована схема и выполнен монтаж пайкой силового каскада на MOSFET IRLB8721

Отказоустойчивая многопоточная CLI-утилита телеметрии Serial/UART
Инструментарий (Serial_host) · Linux / Windows · Rust (std) · 2026 · GitHub

Разработан нативный хост-клиент (Linux/Windows) для двустороннего взаимодействия с микроконтроллером. Реализована параллельная архитектура: независимые потоки чтения и записи с безопасной синхронизацией состояний через примитивы AtomicBool. Интегрирован программный расчет контрольной суммы CRC-16, идентичный аппаратному блоку STM32, для предварительной валидации пакетов на стороне ПК. Настроена отказоустойчивая обработка I/O-ошибок (например, при физическом обрыве связи) с функцией горячего переподключения (hot-plug) COM-порта без перезапуска утилиты.

Система контроля температуры с ПИД-регулятором
Курсовой проект · STM32F3DISCOVERY · Rust · 2026 · GitHub

Разработана замкнутая система управления температурой жидкости на базе микроконтроллера STM32. Интерфейс 1-Wire для опроса датчика DS18B20 реализован программно (bit-banging) с валидацией пакетов по алгоритму CRC-8. Математическая модель ПИД-регулятора дополнена релейным режимом (bang-bang) для форсированного нагрева при значительной ошибке. Мощность нагревателя (12 В, 50 Вт) регулируется методом пропорционально-временного управления (time-proportional control) через электромеханическое реле. Обеспечена динамическая калибровка коэффициентов ПИД и уставки командами по UART без остановки работы системы. Реализован вывод телеметрии на OLED-дисплей (I2C) и в терминал. Спроектирована принципиальная электрическая схема в KiCad.
