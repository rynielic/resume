Проекты и опыт

Асинхронный парсер протокола по UART с использованием DMA
Пет-проект · STM32F303 · Rust · 2026 · Код на GitHub

Реализовал неблокирующий прием пакетов переменной длины на уровне регистров (PAC) без оверхеда HAL. Настроил кольцевой буфер DMA (Circular mode) в связке с прерываниями по простою линии (USART IDLE line interrupt). Исключил потерю байтов при высокой частоте потока данных.

Система контроля температуры с ПИД-регулятором
Курсовой проект · STM32F3DISCOVERY · Rust · 2026 · Код и схема

Разработал замкнутую систему терморегуляции на базе микроконтроллера STM32F303. Реализовал опрос датчика DS18B20 по протоколу 1-Wire, вывод телеметрии в реальном времени на OLED-дисплей SSD1306 (I2C) и логирование данных на ПК по UART. Написал алгоритм ПИД-регулятора для управления нагревательным элементом. Спроектировал электрическую принципиальную схему в KiCad.
